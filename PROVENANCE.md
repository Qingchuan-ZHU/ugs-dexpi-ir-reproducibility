# Provenance

This public export is assembled from source commit
`296878ffca9095a0e17bcdc5907ea38d723f78c9`. The source working tree was clean
when the export was created.

The package was assembled through an explicit public-content allowlist. It
contains no copied Git history, branches, source-repository metadata, paper
files, pilot or smoke outputs, private notes, or real environment files.

The six formal result sets, their run metadata, validation records, formal
inputs, runtime code, and the DEXPI reference files were copied from the source
snapshot. All formal evidence files are preserved byte-for-byte in this export
except for the single public-release privacy-sanitized validation record
documented below. Recorded generation commit hashes inside the formal run
metadata remain part of that evidence; no corresponding Git history is included
here.

The DEXPI 2.0.0 reference files are third-party artifacts obtained from the
official DEXPI publication and are identified separately in
`THIRD_PARTY_NOTICES.md` and `standards/README.md`.
